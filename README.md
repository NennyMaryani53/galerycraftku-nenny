
# 🌷 Galery Craftku

## 💐 Tentang Galery Craftku

**Galery Craftku** adalah website katalog buket bunga dan hadiah kreatif. Website ini dibuat untuk membantu pengunjung menjelajahi pilihan buket, menemukan inspirasi hadiah, melihat detail produk, serta membuat buket sesuai preferensi.

Dengan tampilan yang menarik dan navigasi yang sederhana, pengunjung dapat mengenal koleksi produk dan menghubungi Galery Craftku untuk mendapatkan informasi maupun melakukan pemesanan.

## ✨ Fitur Website

- **Beranda** — Memperkenalkan Galery Craftku dan menampilkan produk pilihan.
- **Katalog Buket** — Menampilkan koleksi buket dengan berbagai pilihan produk untuk beragam momen.
- **Custom Buket** — Membantu pengunjung menentukan pilihan buket sesuai keinginan.
- **Estimasi Harga** — Memberikan perkiraan harga berdasarkan pilihan pada fitur custom buket.
- **Galeri & Inspirasi** — Menampilkan foto dan inspirasi rangkaian buket.
- **Testimoni & FAQ** — Menampilkan ulasan serta jawaban atas pertanyaan yang sering diajukan.
- **Kontak** — Menyediakan informasi untuk menghubungi Galery Craftku.

## 🧰 Teknologi yang Digunakan

- **HTML5** — Menyusun struktur halaman website.
- **CSS3** — Mengatur tampilan, tata letak, dan desain website.
- **JavaScript** — Mendukung interaksi dan fungsi pada website.

## 🚀 Menjalankan Project

1. Unduh atau clone repository ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Jalankan file `index.html` melalui browser atau ekstensi Live Server.
